Acerca del proyecto

Información académica del proyecto colaborativo.

Propósito

Construir colaborativamente una interfaz web aplicando HTML, CSS, Bootstrap, JavaScript y Git/GitHub.

Reglas

  • Un alumno, una rama y un módulo.
  • Todos deben respetar la identidad visual.
  • Los componentes comunes se modifican únicamente con autorización.
  • Los cambios se integran mediante Pull Request.
