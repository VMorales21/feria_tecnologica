PROYECTO COLABORATIVO

¿Qué es la Feria Tecnológica?

La Feria Tecnológica es una plataforma web para la gestión y difusión de proyectos tecnológicos, eventos y participantes. Reúne en un solo sitio la información de las actividades de la feria, los proyectos que se presentan y los equipos que los desarrollan.

El sitio se construye como proyecto base de la materia Tópicos Selectos de Desarrollo Web: cada alumno desarrolla un módulo, y entre todos se integra una única aplicación con identidad visual uniforme.

Propósito

Objetivos del proyecto

Aplicar lo aprendido

Construir una interfaz web usando HTML, CSS, Bootstrap y JavaScript.

Trabajar en equipo

Practicar el flujo colaborativo con Git y GitHub: ramas, commits y Pull Requests.

Mantener la identidad

Respetar el navbar, el footer, la tipografía, los colores y los botones comunes.

Diseño responsive

Lograr que cada módulo funcione correctamente en computadora, tableta y celular.

Lineamientos

Reglas del proyecto

  1. Un alumno, una rama y un módulo (feature/nombre-modulo).
  2. No trabajar directamente sobre main.
  3. Todos deben respetar la identidad visual: navbar, footer, tipografía, colores, botones y estructura de carpetas.
  4. Los componentes comunes se modifican únicamente con autorización del docente.
  5. Cada alumno debe realizar al menos 3 commits significativos.
  6. Los cambios se integran mediante Pull Request.
  7. El módulo debe ser responsive y funcionar correctamente.
Metodología

Flujo de trabajo con Git

  1. Clonar el repositorio del proyecto.
  2. Crear una rama propia para el módulo.
  3. Desarrollar el módulo y hacer commits significativos.
  4. Subir la rama al repositorio remoto.
  5. Crear un Pull Request hacia la rama indicada por el docente.
git clone URL_DEL_REPOSITORIO
git checkout -b feature/nombre-modulo
git add .
git commit -m "feat: agrega modulo X"
git push origin feature/nombre-modulo

Identidad visual

Todos los módulos comparten la tipografía Poppins, una paleta basada en azules institucionales, fondo claro y los mismos estilos de tarjetas y botones definidos en css/style.css. Esto garantiza que la plataforma se vea como una sola aplicación, sin importar quién desarrolló cada módulo.
